# 🎮 FallRush

A fast-paced and interactive browser game built with HTML, CSS, and JavaScript.
Catch the falling targets and challenge yourself to achieve a higher score.
The game features smooth controls, responsive gameplay, and a clean modern interface.
Designed to work smoothly across desktop and mobile devices.
Compete with yourself and improve your reaction speed with every round.
Built as a personal web-development project by Rakib Hasan.

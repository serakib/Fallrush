# 🎮 FallRush

A fast-paced reflex game built around timing, focus, and precision.
Catch falling targets before they escape and push your score higher.
Every moment demands quick decisions and sharper reactions.
Designed with smooth gameplay and a clean, responsive interface.
Built to deliver a simple concept with an increasingly challenging experience.
Developed using HTML5, CSS3, and JavaScript.
Created as a personal game-development project by Rakib Hasan.
